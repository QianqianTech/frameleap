# CodeNeo 接入 FrameLeap

- `frameleap-client.codeneo.json`：CodeNeo 的适配文件示例。路径是按常见约定（`~/.codeneo/…`）写的；拿到 CodeNeo 实际的配置位置后，改好再用。
  - 由 CodeNeo 放进 `~/.config/frameleap/clients/codeneo.json`：FrameLeap 自动识别。
  - 或在 FrameLeap 的「设置 › 接入 AI 助手 › 导入客户端适配文件」里导入。
- 对接文档：`../vendor-guide.md`（FrameLeap 设置页「对接文档」按钮下载的就是它）。

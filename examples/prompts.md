# 示例提示词

| 场景 | 对 AI 助手说 |
|---|---|
| 每日资讯 | 用 FrameLeap 做一期今天的 AI 早报，竖屏，1 分钟左右，配男声 |
| 口播后期 | 用 FrameLeap 把 ~/Movies/口播.mp4 剪一下：去掉口误和停顿，加字幕和背景音乐，出抖音和 B 站两个版本 |
| 云端口播 | 我要上传一段口播让 FrameLeap 剪（它会给你上传链接） |
| 软件演示 | 用 FrameLeap 给 https://example.com 做一个 90 秒的产品功能演示视频 |
| AI 生图成片 | 用 FrameLeap 做一条“秋天的贵州”风景短片，6 个镜头，治愈风格 |
| 按模板 | 用 FrameLeap 的“新品种草”模板，产品是保温杯，卖点：24 小时保温、316 不锈钢 |
| 只改几段 | 刚才那条第 3、4 段节奏太慢，帮我只改这两段 |
| 换配音 | 刚才那条换成女声，语速快一点，画面不用动 |
| 审片 | 草稿我看了，字幕再大一点，开头那句删掉 |
| 发布 | 发到抖音和视频号，标题用“3 分钟看懂今天的 AI 大事” |

AI 助手发布前一定会先给你看预览，你说“确认发布”它才会发。

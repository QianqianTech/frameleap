# FrameLeap 视频模式

| kind | 名称 | 需要什么 | 适合 |
|---|---|---|---|
| talking_head | 口播后期 | 原片（本机路径 / URL） | 已录好的口播：去口癖粗剪、字幕包装、推拉镜、配乐、多平台版本；也可换音色、加数字人 |
| news_brief | 每日资讯 | 栏目（AI早报、娱乐早知道、财经早参、科技/汽车早知道、体育早班车或自定义） | 每天的新闻卡片视频；一家公司每期只出一条 |
| software_demo | 软件 / 产品演示 | 网址或软件名、要演示的操作 | 自动操作软件录屏 + 配音字幕 |
| image_story | AI 生图成片 | 主题；可附自己的照片 | 教程、故事、种草；先出草图（manual/auto），确认后出高清终图并图生视频 |
| product_explainer | 产品图解宣传片 | 产品介绍或资料 | 架构图、流程图、数据图的动效讲解 |
| self_media | 热点深度解读 | 领域或话题 | 自动选热点、写稿、配图配音 |
| ai_video | AI 视频 | 画面描述、时长、比例 | 纯 AI 生成的短视频镜头（无旁白） |

常用平台：douyin（抖音）、channels（微信视频号）、xiaohongshu（小红书）、bilibili（B站）、kuaishou（快手）、youtube、tiktok。

常见回复（fl_reply）：
- 审片 / 草稿：“通过”“开头那句删掉”“字幕再大一点”“配乐换轻快一点的”“换成男声”
- 生图成片草图：“确认出片”“第 3 镜改成俯拍”
- 完成后：“再出一个横屏版”“标题改成……”
- 失败后：“重试”
